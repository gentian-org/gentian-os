# Roadmap

Gentian OS moves along six themes. The work itself is tracked in the
[issues](https://github.com/gentian-org/gentian-os/issues) of this repository,
and in those of [gentian-apps](https://github.com/gentian-org/gentian-apps/issues)
and [gentian-ui](https://github.com/gentian-org/gentian-ui/issues).

| Theme | Direction |
|---|---|
| Security and hardening | Narrower access for every workload, verifiable supply chain, stronger identity between services |
| Platform and lifecycle | Simpler operations, versioned upgrades, more scale on the same contracts |
| Users and desktop | A coherent experience across the desktop, the consoles and the App Store |
| Agentic AI | Assistants that act within a person's rights, through a standard tool protocol |
| Certification | Evidence for ISO 27001 and SOC 2 that comes from the running system |
| Cleanup | Fewer mechanisms, each with one owner |

[releases/](releases/) records what has shipped.
